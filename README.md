## 💖 Tentang Proyek

Website portofolio pribadi dengan tampilan **aesthetic, lembut, dan responsif**. Dibuat untuk memperkenalkan diri, menampilkan skill, proyek, dan cara menghubungi aku. Dibangun tanpa framework supaya ringan dan mudah dipelajari.

---

## ✨ Fitur

- 🌙 **Dark / Light mode** dengan toggle yang menyimpan preferensi di browser
- 🎀 **Tema pastel** (pink, lavender, dan peach) yang konsisten
- 🪄 **Animasi halus** saat scroll dan hover
- 📱 **Responsif** di HP, tablet, dan desktop
- 🧁 **Section lengkap**: About, Skills, Projects, dan Contact
- 💌 **Form kontak** yang siap disambungkan ke layanan email
- ⚡ **Ringan dan cepat**, tanpa dependensi berat

## 🚀 Cara Menjalankan

**1. Clone repository**

```bash
git clone https://github.com/username/nama-repo.git
```

**2. Masuk ke folder proyek**

```bash
cd nama-repo
```

**3. Buka di browser**

Buka file `index.html` langsung, atau pakai ekstensi **Live Server** di VS Code agar otomatis refresh.

---

## 🎨 Kustomisasi

### Ganti warna tema

Edit variabel warna di `css/style.css`:

```css
:root {
  --pink: #ffd6e0;
  --lavender: #e6d9f5;
  --peach: #ffe5d4;
  --text: #4a3f4f;
  --bg: #fff9fb;
}
```

### Ganti konten

- **Nama dan deskripsi**: edit bagian *Hero* dan *About* di `index.html`
- **Proyek**: tambahkan kartu baru di section *Projects*
- **Foto**: taruh gambarmu di folder `assets/images/`

---

## 🌍 Deploy ke GitHub Pages

1. Push proyek ke GitHub
2. Buka **Settings → Pages**
3. Pada *Source*, pilih branch `main` dan folder `/ (root)`
4. Klik **Save**, lalu tunggu beberapa menit
5. Websitemu aktif di `https://username.github.io/nama-repo` 🎉
